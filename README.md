# CBRM Prüfungstrainer

Lernseite zur Lehrveranstaltung *Computerunterstützte Gewässermodellierung / Computer Based River Modelling* (BOKU, VU LAWI301273/301284):
Zusammenfassung von Vorlesung (Units 1.1–4.2) und Übungen (HEC-RAS PU 1–5, RSim-2D, RSim-3D), interaktive Rechner (spezifische Energie, CFL, Strickler, Shields, explizit/implizit) und Quiz.

Seite: https://cfandl-stack.github.io/cbrm-pruefungstrainer/

Persönliche Lernzusammenfassung; maßgeblich sind die Originalunterlagen der Lehrveranstaltung.

`index.html` wird mit `python build.py` aus `../CBRM_Pruefungstrainer.html` erzeugt.
